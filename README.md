# Prod-Pusher

Release-only repository for Prod-Pusher.

This repository does not contain application source code, credentials, logs, or build output. It is used only for public release metadata and downloadable release assets.

## Download

Get the latest executable from the [Releases](https://github.com/uditcic/prod-pusher/releases) page.

## Repository Policy

- Do not commit source code, local logs, credentials, archives, executables, or dependency folders.
- Keep release assets attached to GitHub Releases instead of storing them in git history.
- Store secrets outside the repository and provide them at runtime.

## Support

Use the repository issue tracker for release packaging or download issues.
